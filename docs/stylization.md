# 风格化渲染（「3渲2」）与哈特诺村对照

这份笔记记录四件事：一是「3渲2」（用 3D 渲染出 2D 动画质感，原神、旷野之息 / 王国之泪那种画面）的调研和这里的实现，二是村庄对着哈特诺村截图找出的差距和改动，三是第二轮针对房屋体量、台地和布局层次的改动，四是第三轮让房子不再规整干净、有生活痕迹的改动。

## 一、调研：「3渲2」由哪些东西构成

| 手法 | 出处 / 代表 | 作用 |
|---|---|---|
| **明暗分阶**（ramp / 两阶光照） | 罪恶装备 Xrd（GDC 2015，Junya Motomura）、原神角色、各种 BotW 复刻着色器 | 受光面和背光面之间不是一条长渐变，而是一条窄而柔的交界线，画面像赛璐璐动画一样分成「亮面 / 暗面」两块色 |
| **暗部换色而不是变灰** | 罪恶装备 Xrd 的阴影色贴图（暗部乘一张更饱和的颜色）、原神社区复刻着色器的「阴影色」参数 | 暗部保持并加深固有色、略微偏冷，黄墙的暗面是暖赭色而不是橄榄灰 |
| **暗部提亮、整体低反差** | 旷野之息截图实测（下表）、BotW 复刻着色器的「shadow floor」 | 原作暗部亮度 p5 约 0.30–0.42，反差 0.09–0.14，空气通透；写实光照下暗部会掉到 0.1 |
| **轮廓边缘光** | 旷野之息的 contour glow / rim，Roystan 的 toon shader 教程（rim 只在受光侧出现） | 受光一侧的轮廓上一条窄的亮边，把形体从背景里「描」出来 |
| **描边** | 罪恶装备 Xrd、原神角色（反向外壳法，按顶点色控制粗细）；场景常用后期描边（深度 / 法线 Sobel，Unreal / Godot 文档都有现成做法） | 轮廓画线，最「二次元」的一笔；线色取物体本色压暗，而不是纯黑 |
| **平涂、少细节的贴图** | 原神（基于 PBR 的风格化，按美术需求改材质光照模型，miHoYo Unity 分享）、旷野之息手绘贴图 | 大色块 + 少量笔触，细节靠形状不靠噪点；截图实测原作 1–5px / 5–20px 细节量只有写实渲染的一半 |
| **大气、泛光、调色** | 原神的分层天空盒、体积雾、泛光、LUT（第三方分析）；旷野之息的朦胧空气 | 远景收进雾色，黑位抬起、饱和度略高 |

角色专用的手法（SDF 脸部阴影图、头发高光、手绘法线让脸部阴影干净）这里没有角色，暂不涉及。

## 二、这里的实现

全部由 `m.env({ toon, outline })` 控制（0–1，默认 0.8 / 0.6，0 回到原来的写实明暗、关闭描边），改动在共享着色器里，所有地图一起生效：

- **两阶光照**（`src/render/shaders/common.glsl.js` 的 `lighting()`）：原来的柔和交界 × 阴影图得到受光量 L，toon 把它压成 `smoothstep(0.2, 0.5, L)` 的一阶（保留 18% 的原渐变，曲面不至于变成纯平）。投影和自身背光走同一条交界，影子边缘仍是 PCF 的柔边。
- **暗部**：环境光 ×(1+0.75·toon)，阳光 ×(1−0.3·toon)——亮面曝光不变，暗面亮了约一半；暗面颜色先把固有色饱和度推高 35%（保持色相），再乘一个偏冷的阴影色 `uShadeTint`。夜里自动退回写实（交给灯光）。
- **边缘光**（`src/render/props.js`）：toon 把原来的 Fresnel 渐变换成受光侧轮廓上的一条窄亮带，在影子里减弱。
- **描边**（`src/render/post.js`）：合成阶段读场景深度，某像素四邻里有明显更远的（深度跳变超过自身距离的约 5%，或是天空），它就在轮廓上，颜色乘 (0.5, 0.47, 0.55)——本色压暗偏冷。约一像素宽（按分辨率缩放），160m 内由近到远淡出；草写 alpha 0.5 作标记，不描边（否则每根草都会描一圈）；天空 alpha 0。
- **平涂**：建筑贴图的法线起伏 ×(1−0.4·toon)、凹缝变暗从 0.62 收到 0.8；崖壁的裂缝变暗同样收浅；草地上的笔触纹理淡化成大块颜色，地面法线减弱；土路换成浅暖色、少石子、浅起伏。
- **调色**：黑位抬起并略偏冷（`c·(1−0.07·toon) + 0.065·toon`），饱和度 +10%·toon，抵消抬黑带来的发灰。

## 三、村庄：和哈特诺村比差在哪

参考：旷野之息的哈特诺村（`refs/` 里三张）和王国之泪的哈特诺村全景、村长家、旅馆、染坊、东风屋、筒仓等 15 张截图（Zelda Wiki）。按影响大小：

1. **地形（全景里差距最大）**：哈特诺村建在一层层石灰岩台地上，台地之间是两三米到十几米的白色陡坎，房子坐在台地边上，路从陡坎的缺口斜着上去。原来的村子铺在一片均匀的草坡上，房子像摆上去的玩具。→ `t.terrace` 加了 `warp`（陡坎位置随噪声起伏，不再贴着等高线），示例场景把村子所在的坡切成每级 3.4m 的台地，陡坎由崖壁的 crag 起伏变成凹凸的岩面；`m.village` 不再把房子放在「门和街之间隔着一道坎」的位置。
2. **地面**：原作村里是短而平的草坪，土路是浅黄褐色、边缘柔和；原来是没膝的草和深褐色、满是裂纹石块的路。→ `m.village` 会把村里的草「踩短」（新的 `LAWN` 场，草高 ×0.4、略密，参数 `lawn`），土路贴图换成浅暖色、石子少、起伏浅。
3. **房屋材质**：原作墙脚是浅色大石块，瓦是偏橙的大块陶瓦（每排约 30cm，片片高低不一），王国之泪多了奶白色墙。→ 乱石放大到 40cm 以上、灰缝变浅、对比降低；瓦每 2m 6 排 5 列、偏橙、下沿参差、每片略带弧度；灰泥色加了奶白；墙面在檐下有一大片柔和的阴影（原作很明显）。
4. **光照（街景和近景里差距最大）**：原作暗面明亮、偏暖，整体通透；原来暗面发灰发绿、反差大。→ 第二节的卡通光照。

## 四、第二轮：单体体量、台地、布局、附属物

上一轮之后再对着王国之泪的十几张截图看，差距最大的已经不是材质和光照，而是**形体**。按影响排序：

1. **单体体量（核心）**：哈特诺村几乎没有「一个盒子加一个双坡顶」的房子。村长家是主屋加一座高出屋脊几米的方塔，旅馆是主屋、后面的翼楼和前坡上一排老虎窗，普通民居也常是 L 形或 T 形平面，屋顶在交接处形成天沟。原来每栋房子都是一个盒子，远看像一排排玩具。
2. **地形**：原作的台地不是沿等高线的一圈圈梯田，而是大小不一的岩台，高差从半米到十几米不等，路从缺口里斜上去。
3. **布局层次**：原作有明确的主次——几栋大房子退后一个前院、围着矮墙，正对门有拱门；树也有主次（几棵大树当地标）。原来所有房子大小相近、等距排开。
4. **附属物**：廊架、木平台、柴棚、招牌、藤蔓让房子「有人住」，也打破了墙面的平整轮廓。

改动：

- **复合体量**（`src/objects/buildings.js`）：房子先规划成一组块——主屋、翼楼（主屋前后墙上接出的双坡体量，L / T / 十字形平面）、方塔（临街一角，高出屋脊 3–5m，60° 以上的四坡尖顶，角石和腰线）、老虎窗（埋在前坡里的小双坡体量）——再逐块建墙和屋顶。块与块直接穿插，交线和天沟交给深度缓冲，不需要做布尔运算；被别的块盖住的墙面不开窗、不砌角石（开窗前先检查那个位置是不是落在别的块里）。另有四坡屋顶、屋脊微微下垂、檐口单片瓦参差（只在近景）。参数 `wings` `dormers` `tower` `towerShape` `roofShape`，没给的按 seed 随机：哈特诺风格的房子约一半有翼楼、四成有老虎窗、六分之一有塔。
- **台地**（`t.ledges`）：扭曲过的抖动 Voronoi 把坡面切成一块块平台，每块取所在处的原高度 ± 随机量；相邻两块高差大的地方过渡带窄（陡崖），高差小的地方宽（缓坡）。村子里的宅基地要求整栋房子落在同一块平台上，门和街之间不能隔着坎。
- **布局层次**（`src/objects/village.js`）：离广场最近的两块宅基地盖地标——村长家（方塔、角石、高烟囱，侧墙爬藤，山墙边一个柴棚）和旅馆（翼楼、三个老虎窗、布幡，门前廊架挂灯笼和招牌，山墙边的木平台）；它们退后 5m 的前院，前院围着圆角的抹灰矮墙（`wall.yard`），正对门开一座石拱门（`arch`）。广场和院子边先种几棵树冠宽大的老树，其余的树两三棵一丛。
- **附属物**：廊架、木平台（立柱撑地，栏杆、台阶、通向平台的门）、单坡柴棚（靠山墙，没有空山墙时靠后墙，下面码着劈柴、露出年轮）、铁臂挑出的店招、整面侧墙的常春藤。都算进房屋的占地，杂物、花圃和别家的宅基地会让开。
- 每一级 LOD 都是同一个模型：方塔、翼楼、老虎窗、附属物在三级里外轮廓一致（测试检查包围盒相差不超过 15cm），远处只省掉小构件和叶片数量。

## 五、第三轮：太规整、太干净、没有生活痕迹

对着王国之泪的高清截图（染坊的圆筒仓、村长家、旅馆侧面）放大看，「真实」主要来自三件事，而不是更多的几何细节：

1. **没有一条线是笔直的**：檐口和屋脊微微起伏下垂，瓦一片片高低、深浅不一，筒仓不是正圆、略微倾斜。我们的墙是完美平面、檐口像尺子画的，所以像模型。
2. **墙面从来不是一个颜色**：染坊筒仓的灰泥上是一块块颜色更深的旧补丁，补丁边缘有一圈更暗的线（新抹的一层到此为止），墙脚溅满泥土，檐下和窗下有雨水流痕。
3. **住过的痕迹**：门口的陶罐和花、晾着的布、墙上挂的东西、靠墙的长凳和扫帚、墙根的杂草。环境叙事的常见说法是：每件道具都应该让房子更可信、更有个人气息。

调研要点（环境美术的做旧方法）：脏污积在凹处和墙脚，边角磨损在凸处，雨痕从突出的边沿（檐口、窗台）往下流；纯按规则生成的遮罩太均匀，要乘一层噪声打散；蒙版存在顶点数据里是游戏里最便宜的做法。歪扭的造型要符合房子真实的沉降和老化方式，否则就成了卡通。

改动：

- **手工感**（`src/objects/mesh-builder.js` 的 `sliceGrid` / `warp`，`buildings.js` 的 `warpField`）：每块体量建完后先按全局网格切开大面（近景 1.1m、中景 1.8m、远景 3.2m；切点只由网格决定，所以原来贴合的面切在同一处，变形后不会裂开），再加一个平滑的位移场：墙每米倾斜 2–8mm（方塔 6–14mm），前后左右墙各自在两角之间鼓出或凹进 2–6cm（墙脚、墙角、檐口处为零），屋脊中间下垂 5–20cm、檐口跟着下垂约三分之一，檐口和山墙边沿 1–3cm 的起伏，瓦面 1–2.5cm 的起伏。法线按场的雅可比矩阵一起转，鼓起的墙也会按鼓起的样子受光。老虎窗跟着它所在的屋面变形。场只取决于房子的种子，三级 LOD 弯法相同；代价是近景模型多约 45% 三角形。
- **做旧**（`src/render/props.js`）：灰泥上叠加三层噪声——大块旧补丁（偏暖偏暗，边缘一圈更暗）、零星的新石灰亮斑；墙脚一条参差的泥土带；雨痕：墙面顶点的 aSway 存着「离上方滴水边沿（檐口或窗台）多远」，窗下的墙单独切成一列，所以雨痕从窗台下开始往下流、越往下越淡，竖向拉长的噪声让它成为一道道痕迹。陶瓦：按贴图同样的瓦片格子（6 排 × 5 列、同一个哈希的错位）算出每片瓦的编号，每片自己的深浅，5% 新换的亮橙瓦、7% 发黑的老瓦；整片屋顶晒褪色 / 发暗的大块区域；苔藓成团、偏屋面下部、长在瓦片下沿的阴影里。木头局部发灰；石头墙脚潮湿发暗、长苔。细碎的纹理随像素尺寸淡出，远处不会闪。
- **生活痕迹**（`buildings.js` 的 `livedIn`，独立随机流）：门口一到四个花盆（三种盆型，叶丛加花），长凳（有的带靠背），扫帚和水桶，窗帘（七成窗户，半拉或下半截的咖啡馆帘，每户一种布色），一半人家的窗上压着木过梁，两层房子楼板高度的铁拉结，三十丛墙根杂草，挂钉板上的草药 / 篮子 / 耙子，晾衣绳（三成人家，从空着的山墙或后墙拉出 3.4m，挂三到五件床单衣物，算进占地），墙角雨水桶，屋脊风向标。近景画全部，中景画大件，远景只留影响轮廓的晾衣杆和风向标；LOD 检查各级切换的颜色差都在 5 以内。

还没做的（下一步）：台地边上的挡土墙；外挂楼梯、筒仓、东风屋那种两层木结构；单片松动的瓦（现在只有颜色变化）；更柔的草叶；动画风格的积云。
